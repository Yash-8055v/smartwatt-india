# 3-Day Execution Plan

## Day 1 — Data + ML foundation
1. Download dataset and inspect files.
2. Identify exact source table/frequency.
3. Build preprocessing script.
4. Produce hourly processed CSV.
5. Perform EDA.
6. Implement statistical baseline.
7. Train baseline regression.
8. Save metrics and model artifact.

## Day 2 — Backend + frontend
1. Build FastAPI project.
2. Implement health/metadata/houses endpoints.
3. Implement summary/analysis/anomaly endpoints.
4. Build React/Vite shell.
5. Build dashboard charts and filters.
6. Connect frontend to backend.

## Day 3 — Polish + deployment
1. Add anomaly explanation UI.
2. Add methodology page.
3. Add model metrics.
4. Add tests.
5. Fix CORS and production environment variables.
6. Deploy backend.
7. Deploy frontend.
8. Test public URLs.
9. Prepare screenshots/PPT/demo script.

## Cut order if time is lost
1. Remove Random Forest comparison.
2. Remove prediction form.
3. Keep only hourly analysis.
4. Keep only three pages: Dashboard, Anomalies, Methodology.
5. Never remove statistical evidence or deployment stability.
